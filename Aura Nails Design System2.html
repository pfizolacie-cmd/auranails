Čo vieš o tom, čo robíš na GitHubu?

Áno, viem! 🙌 Cez GitHub vieme web uložiť a dokonca ho rovno spustiť naživo zadarmo cez GitHub Pages.

Potrebujem, aby si ma najprv prepojila so svojím GitHub účtom — otvorím ti na to prihlásenie:

Pripájanie GitHubu

Skvelé! 🤍 Aby som ti web mohol nahrať na GitHub, prepoj prosím svoj účet:

  1. V chate dole klikni na menu „Import" (ikonka v lište na písanie správy)
  2. Vyber „Connect GitHub" a prihlás sa
  3. Keď to bude hotové, napíš mi sem správu (napr. „hotovo") a budeme pokračovať

Keď ťa prepojíš, vytvorím repozitár a nahrám doň celý web. Potom ho vieme jedným klikom spustiť aj naživo cez GitHub Pages (zadarmo, s vlastnou adresou).

Počkám na teba! 💛

asi k mame
Zoznam repozitárov GitHub, Vyhľadávanie dostupných nástrojov

Ešte to celkom nevidím prepojené — tooly na GitHub mi zatiaľ nenaskočili. 🤔 Skús prosím:

  1. Otvor znova menu „Import" v lište na písanie
  2. Skontroluj, či pri GitHub svieti „Connected" (prepojené). Ak nie, dokonči prihlásenie (môže pýtať povolenie pre repozitáre).
  3. Potom mi sem napíš krátku správu (hocičo) — tým sa tooly aktivujú a hneď ti vytvorím repozitár.

💡 Mimochodom — ak by GitHub robil problémy, najrýchlejšia cesta spustiť web naživo je aj tak Netlify Drop (stiahnutý ZIP pretiahneš na app.netlify.com/drop a o 30 sekúnd je web online, bez GitHubu).

Ale GitHub je super, ak chceš mať web verzovaný a spúšťať ho cez GitHub Pages. Skús to prepojenie ešte raz a napíš mi! 💛

spravím to ručne

Jasné, pohodička! 🤍 Ručne to zvládneš úplne v pohode. Tu je rýchly postup, ak by si chcela web na GitHub + spustiť cez GitHub Pages:

1. Vytvor repozitár

  • Na github.com → New repository → daj mu názov (napr. aura-nails) → Create

2. Nahraj súbory

  • V repozitári klikni „Add file" → „Upload files"
  • Rozbaľ stiahnutý ZIP a pretiahni do okna celý obsah (súbor index.html, všetky .jsx, a priečinok assets)
  • ⚠️ Dôležité: nahraj obsah priečinka, nie priečinok deploy samotný — index.html musí byť v koreni repozitára
  • Dole klikni „Commit changes"

3. Spusti naživo (GitHub Pages)

  • V repozitári Settings → Pages
  • V „Branch" vyber main a priečinok / (root) → Save
  • O chvíľu ti GitHub dá adresu typu https://tvojmeno.github.io/aura-nails 🎉

⚠️ Nezabudni: po spustení sprav prvú testovaciu rezerváciu a v e-maile klikni „Activate Form", nech ti rezervácie chodia.

Keby čokoľvek zlyhalo (alebo Pages ukáže prázdnu stránku), pošli mi screenshot a poradím. A keď to budeš chcieť celé prejsť znova cez mňa, stačí prepojiť GitHub. Držím palce! 💛

Aha — problém bol v tom, že som po čistení zmazal priečinok deploy/, takže odkaz na stiahnutie ukazoval do prázdna. Znova ho poskladám a pošlem nanovo. Dopĺňam assety a návod:

Stiahnite si Aura Nails — web (ZIP na stiahnutie)

Skús to teraz — ZIP je nanovo pripravený (klikni na kartu vyššie). 📦

Predtým nešiel stiahnuť, lebo som po čistení omylom zmazal priečinok, na ktorý odkaz ukazoval. Teraz je späť aj s návodom (NÁVOD-na-spustenie.txt). 💛

Daj vedieť, či sa stiahol! Ak by stále nešiel, napíš mi a skúsime inú cestu.
