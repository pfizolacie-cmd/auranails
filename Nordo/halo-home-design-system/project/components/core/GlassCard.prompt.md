The frosted panel every other surface is built on — use for tiles, sheets and grouped controls; only use `tone="solid"` when the content needs full legibility (alarm times, forms).

```jsx
<GlassCard tone="light" glow>
  <span>Smart Light</span>
</GlassCard>
```

Tones: `light` (default frosted), `dim` (smoked, for stacking on a bright backdrop), `solid` (porcelain, dark text).
