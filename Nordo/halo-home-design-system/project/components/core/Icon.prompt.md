Tintable Lucide glyph — use it anywhere Halo Home needs an icon; it inherits `color` from its parent so it works on glass and on solid cards alike.

```jsx
<Icon name="lightbulb" size={22} />
```

House icons used across the kit: `house`, `lightbulb`, `thermometer`, `settings`, `bell`, `search`, `arrow-left`, `menu`, `plus`, `minus`, `wifi`, `heart`, `play`, `pause`, `rotate-ccw`, `rewind`, `fast-forward`, `speaker`.
